# namespace EU.CqrXs.Crypt.Cipher.Symmetric

### classes

### AesNet
	a direct implementation of Aes without Legion of Bouncy Castle

### CryptBounceCastle
	provides encryption / decryption for several algos with Legion of Bouncy-Castle Framework

### Des3Net
	Provides 3Des without Legion of Bouncy-Castle Framework

### ZenMatrix
	my own simplest possible symmetric block cipher, where values and position of bytes are mapped through ZenMatrix

### ZenMatrix2
	my own simplest possible 256 key- and blocksize symmetric block cipher,where values and position of bytes are mapped through ZenMatrix2
